One line about office life: HR's "anonymous" feedback form asks for your employee ID, department, and desk number — so you give every question top marks and sign it "Anonymous". Running `main.py` prints that exact line to stdout and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
python3 main.py
```
